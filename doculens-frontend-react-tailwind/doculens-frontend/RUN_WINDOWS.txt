DOCULENS FRONTEND — QUICK START

1. In backend terminal:
   python -m uvicorn main:app --reload

2. In backend .env make sure this line exists:
   CORS_ORIGINS=http://127.0.0.1:5173,http://localhost:5173
   Restart FastAPI after changing .env.

3. Open doculens-frontend in VS Code, Terminal > New Terminal:
   npm install
   Copy-Item .env.example .env
   npm run dev

4. Open http://127.0.0.1:5173
5. Sign in using the same email/password as the DocuLens backend.

Your MySQL database and backend remain unchanged.
